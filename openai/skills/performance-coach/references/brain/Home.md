# Corner Coach Brain

**Agents / ChatGPT / Claude / Grok: read [[APC-SYSTEM-PROMPT]] first. It is mandatory.**

Host adapters (how to wire each product): [[FOR-AGENTS]] · [[CHATGPT]] · [[FOR-CLAUDE]] · [[GROK]] · [[FOR-CURSOR]]

The customer-safe knowledge layer for RapportScore.ai: what every measurement means, how belts really work, how coaching runs, and what the coach promises. Consumers share it: humans reading in Obsidian, the ask_coach knowledge bake, the corner-coach skill, and **portable cloud OKF bundles** so any RapportScore user can load the same APC craft on their own data ([[okf-portable-apc]]). One quality bar governs every note: no LLM reading a note should ever have to guess what a measurement means.

RapportScore is science-based, AI-enhanced. Deterministic measurement categories produce 2,400+ data points per recorded call; interpretation happens after measurement. Notes carry verbatim product numbers with sources; exploratory numbers are labeled; gaps are logged, never papered over.
