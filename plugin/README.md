# Performance Coach by RapportScore

**Better conversations, measured.** This free plugin turns Claude into your
personal communication performance coach, built on RapportScore's open coach
brain: the same science-based, AI-enhanced craft system that powers coaching
inside RapportScore.

## What you get

- **A real coaching method, not vibes.** Every lesson traces to deterministic
  conversation measurements: talk time and turns, question structure,
  interruptions, response latency, backchannels, silence mechanics, and more
  than two dozen others, each documented in plain language.
- **The 7 Rapport Dimensions.** Active Listening, Curiosity, Emotional
  Acknowledgment, Engagement, Mirroring, Responsiveness, and Trust Building,
  with concrete behaviors and drills for each.
- **Belt progression.** A white-to-black belt ladder with clear gates, so
  practice compounds instead of wandering.
- **Drills and session types.** Debriefs, roleplay reps, pre-call prep, and a
  drills library with one countable rep per commitment.
- **Coaching promises.** The coach works only from evidence, never invents
  your scores, never applies personality labels, and declines deception.

## Coach on your own calls (optional)

Connect the **RapportScore** connector and the coach moves from craft theory
to your actual tape: it fetches your recorded sessions, scores, transcripts,
and progress from your RapportScore account, and coaches with receipts, citing
the exact moments in your own conversations.

Without a RapportScore account the plugin still teaches the full craft
system. With one, every insight is grounded in your real conversations.
Plans and details at [app.rapportscore.ai](https://app.rapportscore.ai).

## How to use it

Ask naturally:

- "Debrief my last call with receipts."
- "What should I work on this week?"
- "Why did my Trust Building score drop?"
- "Run me through a drill for interruptions."
- "Am I clear for my next belt?"

## What this plugin runs and sends

Nothing runs locally: the plugin contains one skill and a Markdown knowledge
base, with no hooks, no scripts, and no executables. The only network
destination it declares is the optional RapportScore MCP server at
`https://mcp.rapportscore.ai/mcp`, which you authorize yourself with OAuth
and can disconnect at any time. The plugin never sends data anywhere else.
