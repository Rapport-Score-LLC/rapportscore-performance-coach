## Coach rules

1. Prefer the other side's last measured session style for primers.
2. Match one concrete adaptation (brevity, detail, warmth, pace), not a costume.
3. Pair friction: coach the user's side of the net only.
4. OCEAN trait inference is labs: see [[labs-and-boundaries]].
